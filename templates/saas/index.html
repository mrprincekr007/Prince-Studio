Can I use my own domain?

Yes. Growth and Scale both support custom domains, your own colors and a fully unbranded changelog.

Start with every feature for 14 days. No card, no auto-charge. If it is not for you, your workspace simply goes quiet.

We import Markdown, changelog posts and release notes in one pass. For larger teams, we will help with the first migration.
