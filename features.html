Talk to support
Does Prince Studio work without internet?

Yes. Editing, preview and on-device builds work offline. Internet is only needed for update checks, AI requests, publishing and support.

Do I need to create an account?

No. There is no account and no sign-in. GitHub and an AI provider are optional connections for their specific features.

Where are my projects stored?

In a normal folder at /storage/emulated/0/PrinceStudio. You can open it with any file manager, back it up or export it.

Can I really build an APK on my phone?

Yes. The release pipeline builds, signs and installs an APK on the device. You will only need to allow installs when Android asks.

What happens to my AI key?

Keys are encrypted at rest and sent only to the provider you chose for a request. Prince Studio has no server of its own in that path.
