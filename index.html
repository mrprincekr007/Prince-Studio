FAQ

Questions, answered.

Everything about price, accounts, files and Android support.

Talk to support
Is Prince Studio free?

Yes. The app is free to download and use. If you connect an AI provider, that provider may charge for API usage — that cost goes to them, not us.

Will it work in India?

Yes. Prince Studio is not region-locked and runs on any supported Android phone. In India, Google AI Studio and Groq both offer free API keys, and GitHub Pages works normally.

Do I need an account?

No. Open the app and start a project. You only need a GitHub account if you choose to publish to GitHub Pages.

Does it work offline?

The editor, preview and file management work offline. AI, publishing and the support form need an internet connection.

Will my files be uploaded somewhere?

No. Projects stay on your phone unless you use a connected feature such as AI, publishing or export. See the privacy policy for details.

Why is it not on the Play Store?

Prince Studio is distributed as a signed APK directly from this site, so updates are not delayed by store review. You install it once; future versions install the same way.

What Android version do I need?

Android 7.0 (API 24) or newer.
